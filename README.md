# PS Vault releases

Installers for PS Vault on macOS Apple Silicon and Windows x64.

Download the latest version from [Releases](https://github.com/psalles00/ps-vault-releases/releases/latest).

This repository contains public installers and signed update manifests. Application source is maintained separately in a private repository. Never upload vault contents, credentials, or global sync keys here.

See each release for supported features, verification status and platform limitations.
